キングダム覇道 親睦パズルソルバー v2
========================================

■ v2の変更点
- 完成図で、各ピースの外周を太い黒線で表示
- 各ピースに①〜⑥の番号を付け、同色が隣接しても判別しやすく改善
- 解答候補を大量表示せず、次の3種類に整理
  1. C多め：Cを最優先、次にB
  2. B多め：Bを最優先、次にC
  3. A多め：Aを最優先、次にB
- 各候補についてC・B・Aの使用数を表示
- 3候補を個別にPNG保存可能

■ 使い方
1. index.html をChrome / Edge / Safariで開きます。
2. 問題スクショを選択、ドラッグ＆ドロップ、またはCtrl+Vで貼り付けます。
3. 白く表示された盤面マスを確認します。誤認識はマスをタップして修正できます。
4. 色・最低ランク・必要個数を条件として設定します。
5. 「解答を探す」を押します。
6. C多め・B多め・A多めの3候補から選びます。

■ 重要仕様
- ピースの回転は禁止です。
- ピースの反転は禁止です。
- 登録した45ピースの向きを、そのまま使用します。
- 「B以上」はAまたはB、「C以上」はA・B・Cを意味します。
- 条件の数量は、対象となるピースの使用個数です。
- 同じランク・色・番号でも形が違うものは①②で別ピースとして登録しています。
