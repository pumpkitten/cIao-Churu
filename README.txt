キングダム覇道 親睦パズルソルバー
=====================================

■ 使い方
1. index.html をChrome / Edge / Safariで開きます。
2. 問題スクショを選択、ドラッグ＆ドロップ、またはCtrl+Vで貼り付けます。
3. 白く表示された盤面マスを確認します。誤認識はマスをタップして修正できます。
4. 色・最低ランク・必要個数を条件として設定します。
5. 「解答を探す」を押します。
6. 複数解がある場合は「前」「次」で切り替え、完成図をPNG保存できます。

■ 重要仕様
- ピースの回転は禁止です。
- ピースの反転は禁止です。
- 登録した45ピースの向きを、そのまま使用します。
- 「B以上」はAまたはB、「C以上」はA・B・Cを意味します。
- 同じランク・色・番号でも形が違うものは①②で別ピースとして登録しています。
- 盤面の自動認識は、ゲーム画面の配置や余白が大きく変わると誤る場合があります。
  その場合も5×5盤面をタップして簡単に修正できます。

■ スマホで使う
GitHub Pagesへ index.html をアップロードすると、スマホからURLで利用できます。
外部ライブラリやサーバー通信は使っていないため、画像は端末内で処理されます。

■ ファイル
- index.html : ソルバー本体（単体で動作）
- README.txt : この説明
